# CARD PRICE FINDER v0.5 TEST

## 更新内容
- カード画像（スクリーンショット）選択、任意切り抜き、ブラウザOCR（日本語+英語）、登録前修正、カード画像圧縮保存
- 既存カードの編集、必要枚数の登録
- メルカリ販売済みスクリーンショットの複数枚OCR、候補の価格・名称修正、手動追加、除外・復帰、最大10件の中央値
- 主要専門店5社に加え、楽天市場とAmazonを別枠で検索（リンクのみ）
- 既存の `cpf_v2` 保存キー、既存 `cards`/`prices`/`shops` 形式を維持。`sold` フィールドを追加。

## テスト手順
1. **更新前に必ず** 現行アプリの「店舗・データ」からバックアップを保存する。
2. ZIPを展開し、`index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `README.md` の5ファイルをリポジトリ直下にアップロードする。既存の `icon-192.png`, `icon-512.png` は削除しない。
3. アプリを開き、登録済みカードが残っていることを確認する。
4. 画像を選択、切り抜き確認、OCR、修正、登録、編集を試す。
5. メルカリ販売済みスクショを読み込み、OCR候補を修正して保存、除外と復帰、中央値を確認する。
6. 通販検索タブで主要5社＋楽天市場＋Amazonのリンクを確認する。

## 注意
- OCRは Tesseract.js をCDNから初回取得するため、初回はネット接続が必要。カードの画像認識精度は保証されない。
- メルカリ一覧画像のOCRでは、商品単位の自動区切りは完全ではない。候補は必ず目視で確認する。買取表・セット品・別レアリティは除外する。
- 異常値は候補の注意表示にとどめ、ユーザーが除外・復帰できる。価格のみで自動除外はしない。
- OCR候補の重複は同一ファイル名・商品名・価格の一致のみ除外する。異なるスクショに写る同一出品は手動で除外する。
- 画像を多数保存するとブラウザ保存容量の上限に達することがある。定期的にバックアップする。
- 通販サイトへは自動アクセスしない。価格/在庫自動取得・20店舗への拡張・X通知は今回の対象外。
- 既存アプリのすべての画面・操作との完全な互換性は端末で未検証。必ずバックアップしてテストする。
