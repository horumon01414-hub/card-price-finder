# CARD PRICE FINDER 試作版 v0.2

## 起動
GitHub Pages等のHTTPS環境に配置してiPhoneのSafariで開き、「共有」→「ホーム画面に追加」でPWAとして利用できます。

## 実装済み
- 6タイトルのカード登録、優先度、カード番号・レアリティ・版のメモ
- 大須近辺のカードショップ候補をボタンで選んで実店舗価格を登録
- 価格、送料、在庫、状態、確認日時の記録
- 通販は異なるサイトの最新価格を2〜5店舗分使い中央値を計算
- メルカリは販売済み記録の直近10件（不足時は記録件数分）の中央値を計算
- 販売中価格がメルカリ相場を下回る場合の表示
- 店舗候補の追加・削除
- JSONバックアップと復元

## 未実装・注意
- 通販・メルカリ・実店舗情報の自動取得は未実装です。各サービスの規約・許可されたAPI等を確認してから追加します。
- 価格データは手入力の試験用です。実際の購入前に販売元で価格・在庫・状態を確認してください。
- データは利用中のブラウザ内に保存され、端末間同期はありません。
- これは仮版です。正式運用前に動作確認と仕様調整が必要です。
